# 宝元三年（1040）疆域

这一版格子是给战略地图用的近似，不是谭其骧图的数字化，也不是 CHGIS。投影仍是兰伯特等角圆锥（标准纬线 25°N / 45°N，中央经线 112°E），一格约 57 公里。政权写在 `data/map/map_1040.json` 的 `owners` 里，规则在 `tools/generate_map.py` 的 `faction_of`，由 `tools/retouch_1040.py` 重涂。海岸对不上的格子会改海陆，其余地形不动。

## 依据

- 谭其骧《中国历史地图集》北宋、辽、西夏幅，取北宋中期、澶渊之盟以后、熙河开边以前的样子。
- 宋辽界河沿白沟 / 拒马河。周世宗收回瀛、莫，所以雄州、沧州在宋；易州、涿州、幽州在辽。
- 燕云十六州在辽。朔州和代州的格心几乎在同一纬线上，界线在雁门附近向南弯一下，朔州归辽、代州和府州归宋。
- 西夏北界含河套、兴庆和河西走廊。1028–1036 年已取甘、凉、瓜、沙，沙州归夏，高昌（吐鲁番）仍是西州回鹘。
- 宋夏之间以横山为界，线在延州、庆州、环州之北。银州、夏州、盐州在北。麟州、府州在黄河东岸，仍是宋的河东突出部。
- 唃厮啰的核心在青唐、邈川。秦州仍属宋（熙河是熙宁以后的事）。川峡西缘的雅州、黎州留在宋，再往西的高原算吐蕃诸部，和青唐连成一片。
- 大理在云南，不到成都盆地。交趾是李朝的红河三角洲，邕州仍属宋。高丽在鸭绿江一线以南、本图西岸以东。台湾不在北宋路分里，海上无主。海南岛在琼州海峡以南，属宋，和大陆不是同一片陆地。
- 海岸按今岸线核对过：渤海留白，山东半岛东端收到成山头，长江口有一块三角洲，雷州半岛伸到海峡，海南、台湾、朝鲜半岛都在。一格约 57 公里，岸线仍然是折线。
- 黄河用 1048 年商胡决口以前的京东故道：过澶州、大名，在滨州一带入渤海西南，不走后来的海河北流。长江、淮河仍入海；淮河口在黄海。
- 高山脊划进所在政权，避免秦岭、太行、贺兰把国土切成碎片。海和湖无主，所以洞庭、鄱阳不会被画成国界，海岸和地图外缘会画。

## 画法

国界用该方颜色：北宋朱红，辽深蓝，西夏赭紫，吐蕃青绿，大理绿，交趾金，高丽青，回鹘沙色。相邻边的中点连成一条线，接头用圆帽把尖角磨圆。线是单独的一条，宽按屏幕像素算：战略约 5 像素，默认缩放约 7 像素，靠近时约 8 像素，外侧深、中心是政权色。边界两侧各铺本方 30% 的色，从国境向内淡出约半格，不盖住国境线本身。路分界没有画。

按 M，或点小地图，进入全图。镜头框住有主的陆地。每个政权铺 45% 的底色，并标国名。再按 M 回到原处；在全图里点小地图，则落到那一格。小地图用纯色填政权，只在国界上描圆线。

## 这张图盖不住的地方

底板只到大约 87°E–134°E、17°N–48°N。辽的蒙古高原只画了南缘，回鹘只到高昌附近。一格的宽度会把界河、横山抹平到格边上，城的归属以格心为准，和城里记录的政权一致。
