# 我带着AI穿越大宋

2030 年的旅人带着顾问终端「豆沙包」和一块太阳能板，在庆历前后魂穿宋仁宗。这是单人、中文界面、六边形战略地图的回合制原型，用 Godot 4（GDScript）写成，并导出为不依赖 SharedArrayBuffer 的网页版。

设计依据见 [docs/设计文档.md](docs/设计文档.md)。当前是第一段可玩地基，不是完整 Demo。

## 环境

- Godot **4.3 或更新**（本仓库用 4.7.2 导出）。渲染器为 GL Compatibility。
- 网页导出模板用 **Web（无线程）**：`web_nothreads_release`。
- 界面中文是 [Noto Sans SC](https://github.com/notofonts/noto-cjk)（SIL OFL 1.1）的常规字重子集。网页没有系统字体，`tools/build_ui_font.py` 只留下游戏里用到的字，写成 `art/fonts/ui_zh.ttf`，运行时再从 `art/fonts/ui_zh.bytes` 装进 `FontFile`，并关掉系统字体回退。仓库里仍留着 Fusion Pixel 的 OFL 字体文件，导出时排除，不打进网页包。

## 直接玩网页版

构建产物在 `build/web/`。需要给 `.wasm` 正确的 MIME，且**不要**加 COOP/COEP 头。

```bash
python3 tools/serve.py
```

浏览器打开 <http://127.0.0.1:8734/> 。默认端口可用环境变量 `PORT` 改。

## 在 Godot 里运行

用 Godot 4.3+ 打开本目录，运行主场景 `scenes/main.tscn`。界面按 1280×720 绘制，并用分数缩放跟着窗口走，打开 HiDPI，这样中文不会先画小再被放大。渲染器必须是 GL Compatibility，网页导出才能跑。

规则自测（无界面断言）：

```bash
godot --headless --path . -- --test
```

## 重新导出网页

把 Godot 可执行文件放在 `PATH` 上，或设置 `GODOT`。导出预设 `Web` 已关闭线程，并关闭跨源隔离头。

```bash
export GODOT=/path/to/godot
bash tools/export_web.sh
```

预设会把 `data/**/*.json` 和字体打进包。占位像素图由脚本预加载，会随资源一起导出。

## 操作

- 左键选择己方单位，或查看敌军与地块。
- 右键走到高亮格，或点射程内的敌军，弹出战斗预览后选「开战」。
- 滚轮缩放三档。拉近时镜头更倾斜，拉远时更俯视。中键拖动，方向键或 WASD 平移。中键点一下而不拖动，和下达右键命令相同。
- 回车或「结束回合」：西夏行动，然后进入下一月。空格切换仍可动的宋军。F 驻扎。
- F5 写入存档槽一，F9 读取。界面里的「存档 / 读档」含自动档与三个槽。网页上同时写入 `localStorage`（键名 `songgame_slot_0` 到 `songgame_slot_3`）和 Godot 的 `user://saves`。
- Esc 关闭弹层或取消选择。

开局是宝元三年正月，镜头在延州。西夏铁鹞子、步跋子、部族骑兵在城外，辽的皮室军在幽州按兵不动。

## 这一段做了什么

- 场景、自动加载单例、JSON 数据：地形、势力、单位、76 座城、42 项科技、建筑表、豆沙包台词、1040 开局。
- 尖顶六边形地图，64×68，约 57 公里一格。兰伯特等角圆锥（标准纬线 25°N / 45°N，中央经线 112°E）。地形、河流、疆界和城名都在这张图上。这是脚本生成的地理近似，不是 ETOPO / CHGIS。
- 地形是程序网格：平原、黄土、沙漠、丘陵、雪线以上的山峰、森林（实例化的低模树）、沿六边的河、以及带浅滩的海。灯光是一盏带阴影的方向光，色调映射用 Filmic。没有体积雾和 SDFGI，因为网页 Compatibility 渲染器做不到。
- 平移、缩放、悬停、地块说明、小地图。城名按缩放和屏幕间距隐藏，避免叠在一起。
- 月回合、年号（宝元 / 康定 / 庆历 / 皇祐）、天气、太阳能发电与电池、城市产出和军饷的粗结算。
- 移动力、地形消耗、控制区、寻路。远程攻击攻方不受反击。伤害按设计文档：`30 × e^(±0.04 × 战力差) × 0.8–1.2`，并计入地形、城墙、渡河、侧翼、将领、伤势、兵种与冲锋。
- 西夏会靠近、攻击或在残血时朝兴庆撤。辽军不动。
- 豆沙包从 `data/dialogue/doushabao.json` 抽台词。科技树可以打开看，本段不能研究。
- 存档为 JSON，再 gzip、再 base64。

## 下一里程碑

建议做设计文档里的 M2 / M3，而不是继续堆系统：

1. 战争迷雾、补给与断粮。
2. 三川口做成真正的剧本事件，而不是开局把三支西夏部队放在延州城下。
3. 占城、征兵、建造。电力可以花在研究上，科技效果开始生效。
4. 高士气溃逃、城池占领、雨天对远程的完整结算。
5. 单位和城还是低模方块，离文明式的手绘模型还有距离。

## 已知问题

- 地图是规则化的第一版地理，海岸、沼泽、黄河旧道都是近似。塘泺只有很少几格。
- 宋朝城市很多，军饷很少，国库每个月都会涨。这不是平衡后的经济。
- 没有迷雾、补给、占领、研究、民夫和历史事件。西夏只做「靠近并打」或「残血回兴庆」。
- 大河不挡路，只在近战里扣战力。雪天只减少可用移动力。
- 兵模、房屋和豆沙包的脸是程序做的，不是雕刻模型或手绘贴图。山体也是六边形抬高再收成峰，不是单独的山脉网格。
- 存档版本是 1。以后改了字段，旧档不会迁移。
