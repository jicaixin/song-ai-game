# 我带着AI穿越大宋

2030 年的旅人带着顾问终端「豆沙包」和一块太阳能板，在庆历前后魂穿宋仁宗。这是单人、中文界面、六边形战略地图的回合制原型，用 Godot 4（GDScript）写成，并导出为不依赖 SharedArrayBuffer 的网页版。

设计依据见 [docs/设计文档.md](docs/设计文档.md)。当前是第一段可玩地基，不是完整 Demo。

## 环境

- Godot **4.3 或更新**（本仓库用 4.7.2 导出）。渲染器为 GL Compatibility。
- 网页导出模板用 **Web（无线程）**：`web_nothreads_release`。
- 界面中文关掉系统字体回退。项目主题是 `ui/theme.tres`：标题用思源宋体粗体，正文用霞鹜文楷，年号和标题屏用马善政。马善政没有的字（包括「祐」）回落到思源宋体。地图上的城名、势力名用同一套思源宋体常规字重。仓库里仍留着 Fusion Pixel 的 OFL 字体文件，导出时排除。

## 直接玩网页版

构建产物在 `build/web/`。需要给 `.wasm` 正确的 MIME，且**不要**加 COOP/COEP 头。

```bash
python3 tools/serve.py
```

浏览器打开 <http://127.0.0.1:8734/> 。默认端口可用环境变量 `PORT` 改。

## 在 Godot 里运行

用 Godot 4.3+ 打开本目录，运行主场景 `scenes/main.tscn`。界面按 1280×720 绘制，并用分数缩放跟着窗口走，打开 HiDPI，这样中文不会先画小再被放大。渲染器必须是 GL Compatibility，网页导出才能跑。

地图上的城用 `art/models/song_city/clusters/` 里的低模城池（1 单位 = 1 米，六角外接圆 10 米）。运行时按本图六角外接圆 18 放大 1.8 倍：都城用 `cluster_capital`，州府用 `cluster_walled`，县城用 `cluster_town`，并按城名转 60° 的整数步。顶点色乘在底色上，所以材质打开了 `vertex_color_use_as_albedo`。

规则自测（无界面断言）：

```bash
godot --headless --path . -- --test
```

## 重新导出网页

把 Godot 可执行文件放在 `PATH` 上，或设置 `GODOT`。导出预设 `Web` 已关闭线程，并关闭跨源隔离头。

```bash
export GODOT=/path/to/godot
bash tools/export_web.sh
```

预设会把 `data/**/*.json` 打进包。立绘按有损压缩导入（全身约 0.58，半身约 0.68，头像与相框约 0.75），只带半身、头像和相框；1024×1536 的全身原图只留给赵祯和豆沙包。

## 操作

- 左键选择己方单位，或查看敌军与地块。
- 右键走到高亮格，或点射程内的敌军，弹出战斗预览后选「开战」。
- 滚轮缩放三档。拉近时镜头更倾斜，拉远时更俯视。中键拖动，方向键或 WASD 平移。中键点一下而不拖动，和下达右键命令相同。
- M 进入全图。全图只留「按 M 返回」，不挡疆域名。再按 M 回到刚才的位置。平时右下角是小地图，点它落到那一格。
- 回车或「结束回合」：西夏行动，然后进入下一月。空格切换仍可动的宋军。F 驻扎。
- T 格物图，P 控制台，J 匠作院，I 百工图，L 贤才录，Y 朝堂，H 史册，E 时事，R 外交。
- F5 写入存档槽一，F9 读取。界面里的「存档 / 读档」含自动档与三个槽。网页上同时写入 `localStorage`（键名 `songgame_slot_0` 到 `songgame_slot_3`）和 Godot 的 `user://saves`。
- Esc 关闭弹层或取消选择。

开局是宝元三年正月，镜头在延州。西夏铁鹞子、步跋子、部族骑兵在城外，辽的皮室军在幽州按兵不动。

## 这一段做了什么

- 场景、自动加载单例、JSON 数据：地形、势力、单位、76 座城、43 项科技（农、工、械、商、军、电，另有中枢）、建筑表、豆沙包台词、1040 开局。
- 尖顶六边形地图，64×68，约 57 公里一格。兰伯特等角圆锥（标准纬线 25°N / 45°N，中央经线 112°E）。地形、河流、疆界和城名都在这张图上。这是脚本生成的地理近似，不是 ETOPO / CHGIS。
- 地形是程序网格，颜色按顶点在六边之间混开，再叠一层噪波，所以不再是一格一个纯色。平原是橄榄绿，黄土是浅赭，沙漠是浅沙色，草原是灰绿。海从岸边的青绿过渡到深水，河边是窄的蓝色。远景有很淡的指数雾。灯光是暖色方向光加一点天光，色调映射用 Filmic。没有体积雾和 SDFGI，因为网页 Compatibility 渲染器做不到。山脊、丘陵、黄土塬、森林和城边的田亩用 `art/models/song_terrain/` 里的模型，经 `WorldMap.spawn_hex_features()` 按连通方向摆上连续地面，不另铺六边形底板。
- 平移、缩放、悬停、地块说明、小地图。城名按缩放和屏幕间距隐藏，避免叠在一起。
- 月回合、年号（宝元 / 康定 / 庆历 / 皇祐）、天气、太阳能发电与电池、城市产出和军饷的粗结算。
- 移动力、地形消耗、控制区、寻路。远程攻击攻方不受反击。伤害按设计文档：`30 × e^(±0.04 × 战力差) × 0.8–1.2`，并计入地形、城墙、渡河、侧翼、将领、伤势、兵种与冲锋。
- 西夏会靠近、攻击或在残血时朝兴庆撤。辽军不动。
- 豆沙包从 `data/dialogue/doushabao.json` 抽台词，对话框用对应表情的相框立绘。赵祯、范仲淹、韩琦、狄青、种世衡、李元昊、辽兴宗、毕昇、苏颂以及燕肃、曾公亮、台谏官、冶铁、窑工、船匠用同一套立绘；大理、交趾、高丽、吐蕃唃厮啰、西州回鹘没有人物图，外交里仍用势力旗帜。
- 格物可以设计、排队、试制。试制完成只记下效果，不改产量。固件和朝堂诏令会改待机耗电、设计进度、试制槽、军饷和部分收入。时事是六条按回合出现的卡片。外交可以派使、开岁赐、开关市。
- 存档为 JSON，再 gzip、再 base64。版本仍是 1，新字段可缺。

## 下一里程碑

建议做设计文档里的 M2 / M3，而不是继续堆系统：

1. 战争迷雾、补给与断粮。
2. 三川口做成真正的剧本事件，而不是开局把三支西夏部队放在延州城下。
3. 占城、征兵、建造。科技效果目前大多只是完成时的一句说明。
4. 高士气溃逃、城池占领、雨天对远程的完整结算。
5. 单位还是低模，城已经换成宋式城池集群。山体仍是程序抬升的脊线，等山脉模型进来再换。

## 已知问题

- 地图仍是约 57 公里一格的近似，不是 CHGIS。1040 年的政权轮廓和依据写在 docs/song_1040_borders.md。塘泺只有很少几格。
- 宋朝城市很多，军饷很少，国库每个月都会涨。这不是平衡后的经济。
- 没有迷雾、补给、占领和民夫。研究、时事、外交都是接在真实数据上的薄层，不是完整模拟。西夏只做「靠近并打」或「残血回兴庆」。
- 大河不挡路，只在近战里扣战力。雪天只减少可用移动力。
- 人物是手绘立绘。兵模仍是低模。山体仍是程序脊线，不是单独的山脉网格。
- 存档版本是 1。以后改了字段，旧档不会迁移。
